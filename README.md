# m-djawadi.github.io

Personal website based on the [Jon Barron template](https://github.com/jonbarron/jonbarron.github.io).

## To customize
1. Replace `images/profile.jpg` with your headshot (square works best).
2. Replace `data/CV.pdf` with your real CV.
3. Edit `index.html`: update the email in the links row, add/edit paper entries in the Research table, fill in award and publication links.
4. Add `images/favicon.ico` (optional).

## Deploy
Push to the `main` branch of `m-djawadi/m-djawadi.github.io`. GitHub Pages serves it at https://m-djawadi.github.io automatically. No CNAME needed unless you use a custom domain.
